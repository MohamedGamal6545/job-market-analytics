ة# Job Market Analytics Dashboard - Wuzzuf

مشروع بسيط لسحب بيانات الوظائف من موقع Wuzzuf وعرضها في Dashboard تفاعلية باستخدام Python.

## فكرة المشروع
المشروع مقسوم لجزئين:
1. `scraper.py`: كود بيسحب أحدث الوظائف من Wuzzuf (اسم الوظيفة، الشركة، والمكان) ويحفظها في ملف `jobs.csv`.
2. `app.py`: كود بيقرأ ملف الـ CSV وبيعرض البيانات على صفحة ويب فيها كروت لأرقام هامة ورسمين بيانيين مع فلتر حسب المدينة.

## المميزات في الـ Dashboard
- 4 كروت (إجمالي الوظائف، عدد الشركات، عدد الأماكن، وأعلى شركة نزلت وظائف).
- رسم بياني لأكثر الشركات التي تطلب وظائف.
- رسم بياني لتوزيع الوظائف على الأماكن/المدن.
- فلتر Dropdown للتصفية حسب المكان.
- جدول بيعرض البيانات الحالية.

## المكتبات المستخدمة
- requests
- beautifulsoup4
- pandas
- dash
- plotly

## طريقة التشغيل

1. تثبيت المكتبات المطلوب تشغيلها:
pip install -r requirements.txt

2. تشغيل الـ Scraper لجمع البيانات:
python scraper.py

3. تشغيل الـ Dashboard:
python app.py

4. افتح المتصفح وادخل على الرابط:
http://127.0.0.1:8050/
